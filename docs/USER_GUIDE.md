# USER GUIDE — TCET SPECIALIZATION TRACKER
**Audience:** Faculty, Academic Mentors, Department Coordinators, and Students  
**Application:** TCET Specialization Tracker (TCET_ST)  
**Version:** 3.2.0  

---

## 1. Introduction

The TCET Specialization Tracker provides academic stakeholders with tools to track specialization course registrations, monitor academic progress, review mentor assignments, and access performance analytics.

---

## 2. Accessing the System

1. Open your web browser (Chrome, Edge, or Firefox).
2. Navigate to: `http://localhost/st/login/`
3. Enter your assigned TCET ERP username and password.
4. Select your role from the login interface if prompted.
5. Click **Sign In**.

---

## 3. Navigating the Enrolled Student Directory

Upon logging into the dashboard, navigate to **Enrolled Students** (`admin/student-info.php`).

### 3.1 Searching and Filtering
- **Quick Search:** Type student name, ERP ID, or Roll Number into the search box to immediately filter records across all columns.
- **Branch Filter:** Select specific departments (e.g., Computer Engineering, Information Technology, AI & DS).
- **Specialization Track:** Filter by approved domain (e.g., Artificial Intelligence, Cloud Computing, Cyber Security).
- **Status Filter:** Toggle between Active students and Inactive/Alumni records.

### 3.2 Inspecting Student Profiles
1. In the student table, locate the student you wish to inspect.
2. Click the **View (Eye Icon)** button in the Action column.
3. The Student Profile modal will display:
   - **Academic Details:** ERP ID, Branch, Admission Year, Current Semester.
   - **Specialization Status:** Program name, enrollment date, and completion progress.
   - **Semester-Wise CGPA:** Historical grade cards and credits earned.
   - **Assigned Mentor:** Faculty mentor name, contact email, and counseling history.

---

## 4. Exporting Reports

Authorized coordinators can download directory listings:
1. Navigate to the Enrolled Students directory.
2. Apply desired branch and batch filters.
3. Click the **Export to CSV** or **Export to Excel** button above the grid.
4. The downloaded spreadsheet will contain sanitized, college-formatted student records.

---

## 5. Security & Session Best Practices

- Always log out of your session by clicking the **Logout** button in the top right user menu when completing administrative tasks.
- Do not share login credentials or temporary authentication cookies.
- Contact the System Administrator if you encounter access restrictions or require mentor reassignment.
